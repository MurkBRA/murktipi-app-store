# Camoufox Playwright Server (LinuxServer Selkies Edition)

**Camoufox** is a stealth, anti-detect Firefox browser fork with engine-level C++ fingerprint spoofing. Built on **LinuxServer's `baseimage-selkies:debiantrixie`** (the exact Selkies + s6-overlay + Nginx + Openbox architecture used by `lscr.io/linuxserver/brave`), this container provides both a full live **Selkies HTML5 web desktop** and the official `daijro/camoufox` **Playwright WebSocket server** (`0.5.9`) for **Playwright**, **Node-RED**, and **n8n**.

## Live Selkies Desktop (`https://<host>:3003/`)

1. Click **Open** in Runtipi to open the Selkies desktop directly at `https://<host>:3003/` (on first direct LAN IP access, accept the self-signed certificate generated by LinuxServer Nginx).
2. Browser windows open borderless and maximized (`NO_DECOR=true`) via Openbox with GPU/DRI3 hardware acceleration support when `/dev/dri` or Nvidia drivers are available.
3. Right-click anywhere in the desktop to launch **Camoufox** manually (`wrapped-camoufox`) or **xterm**, or set `AUTOSTART_BROWSER=true` to launch a persistent Camoufox window on startup.
4. Any browser window opened by Playwright (`firefox.connect`) renders live inside the Selkies desktop when `HEADLESS=virtual`.

## Connecting via Playwright (`firefox.connect`)

Playwright WebSocket automation continues listening on host port **`9223`** (`ws://<host>:9223/` or `wss://<host>:9223/`):

```js
// Node.js / Node-RED (Playwright)
const browser = await playwright.firefox.connect("ws://<host>:9223/");
const page = await browser.newPage();
await page.goto("https://example.com");
await browser.close();
```

If `WS_TOKEN` is set, pass the token via path (`ws://<host>:9223/<token>`), query parameter (`ws://<host>:9223/?token=<token>`), or `Authorization: Bearer <token>`. A lightweight status page and `/json` discovery remain available on port `9223`.

## Persistent `/config` Volume & Key Settings

- **Persistent `/config` Cache (`${APP_DATA_DIR}/data/config:/config`):** Stores SSL certificates, Openbox config, browser profile data, and downloads the pinned Camoufox binary (plus GeoIP only when `GEOIP=true`) on first boot so the Docker image shares LinuxServer Selkies layers cleanly.
- **Permissions (`PUID` / `PGID`) & UI Auth (`CUSTOM_USER` / `PASSWORD`):** Standard LinuxServer user mapping and optional HTTP Basic Auth for the Selkies web UI.
- **Slim Fonts (`SLIM_FONTS`):** Optional flag (`true`) that prunes large (>5 MB) CJK and Apple Emoji font files inside `/config/.cache` to save ~1.6 GB of disk space.
- **Shared Memory (`SHM_SIZE`):** Defaults to `1gb` (matching `lscr.io/linuxserver/brave`) for smooth browser rendering and Selkies video streaming.
- **GeoIP & Fingerprint Controls:** Optional `GEOIP`, `OS_TARGET` (`windows`/`macos`/`linux`), `LOCALE`, `BLOCK_IMAGES`, `BLOCK_WEBRTC`, `DISABLE_COOP`, and `PROXY_SERVER` / `PROXY_USERNAME` / `PROXY_PASSWORD`.
