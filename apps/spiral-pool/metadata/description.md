# Spiral Pool

**Spiral Pool** is a zero-fee, self-hosted solo mining pool supporting **SHA-256d** and **Scrypt** cryptocurrencies with multi-coin routing, merge mining, and Stratum V2 encryption.

## Key Features

- **Single & Multi-Coin Operation**: Dedicate your miners to a single coin or mine multiple SHA-256d and Scrypt blockchains concurrently.
- **Merge Mining & Stratum V2**: Supports auxiliary merge mining (such as LTC+DOGE or BTC+NMC) and Noise-encrypted Stratum V2 connections.
- **Integrated Dashboard & Metrics**: Includes a web control dashboard and PostgreSQL backend for hashrate, worker, and block tracking.

## Configuration

Set the pool mode (`single` or `multi`), primary coin, payout wallet address, and your blockchain node RPC/ZMQ connection details before starting.
