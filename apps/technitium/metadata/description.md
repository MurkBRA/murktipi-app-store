# Technitium DNS Server

**Technitium DNS Server** is an open-source, full-featured authoritative and recursive DNS server designed for privacy, network-wide ad blocking, and local DNS management.

## Key Features

- **Network-Wide Ad & Tracker Blocking**: Blocklists support hosts files, domains, and regex patterns across your entire local network.
- **Encrypted DNS Protocols**: Native support for DNS-over-HTTPS (DoH), DNS-over-TLS (DoT), DNS-over-QUIC (DoQ), and DNSSEC validation.
- **Full Authoritative Zones**: Host primary and secondary DNS zones with a modern web administration console.
- **Real-Time Query Logs & Analytics**: Inspect DNS traffic, top blocked domains, and client statistics in real time.

## Configuration

Set your DNS server hostname, recursion policy, and admin web console password during installation. After starting the container, access the web console to manage zones, forwarders, and blocklists.
