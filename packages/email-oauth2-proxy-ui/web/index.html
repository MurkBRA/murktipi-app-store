Baixar ca-cert.crt
Como instalar o ca-cert.crt no Windows (MailCraft / Outlook / Thunderbird)
  1. Clique em Baixar ca-cert.crt acima.
  2. Clique duas vezes no arquivo e escolha Instalar Certificado.
  3. Selecione Computador Local e avance.
  4. Escolha Colocar todos os certificados no repositório a seguir → Procurar → Autoridades de Certificação Raiz Confiáveis.
  5. Conclua e reinicie o cliente de e-mail (ex.: MailCraft).

Gerar / Renovar Certificado Local

Gera uma CA local X.509 v3 + certificado do servidor com SAN (Subject Alternative Name) compatível com rustls / MailCraft e clientes modernos.
