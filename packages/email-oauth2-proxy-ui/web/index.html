How to install ca-cert.crt on Windows (MailCraft / Outlook / Thunderbird)
  1. Click Download ca-cert.crt above.
  2. Double-click the file and choose Install Certificate.
  3. Select Local Machine and click Next.
  4. Choose Place all certificates in the following store → Browse → Trusted Root Certification Authorities.
  5. Finish and restart your email client (e.g. MailCraft).
